# Django Cards Project

## 📌 Project Overview
This project is a web application developed using Django. It displays different types of cards with images, descriptions, and other details using HTML and CSS templates.

## 🛠️ Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite

## ✨ Features
- Card-based user interface
- Images and descriptions
- Organized templates
- Static files management
- Responsive and simple design

## 🚀 How to Run the Project

1. Clone the repository:
```bash
git clone https://github.com/pranathinatte/django-cards.git
```

2. Open the project folder:
```bash
cd django-cards
```

3. Create a virtual environment:
```bash
python -m venv myenv
```

4. Activate the environment (Windows):
```bash
myenv\Scripts\activate
```

5. Install Django:
```bash
pip install django
```

6. Run migrations:
```bash
python manage.py migrate
```

7. Start the development server:
```bash
python manage.py runserver
```

8. Open in your browser:
```text
http://127.0.0.1:8000/
```
